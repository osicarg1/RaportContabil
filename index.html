Generator email/raport balanta pe conturi

Incarca un fisier de balanta pe conturi (CSV/XLS/XLSX/PDF) si obtine instant un rezumat executiv pentru administrator.

Ce coloane cauta aplicatia?

Aplicatia identifica foile anuale (ex: 2024, 2025, 2026), conturile contabile si totalurile relevante (ex: Total Venituri, Total Cheltuieli, cont 121) pentru analiza automata.

Sincronizare in cloud (Cloudflare) - optional

Conecteaza aplicatia la propriul tau API Cloudflare (Worker + D1) pentru a pastra istoricul analizelor si a-l regasi pe orice calculator. Vezi pasii de instalare in worker/README.md.
